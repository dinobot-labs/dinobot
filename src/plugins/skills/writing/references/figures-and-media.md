# 그림과 도식 — 인라인 SVG 규칙

정적 HTML 글이라면 그림을 인라인 SVG로 만든다. 외부 이미지 요청도, 빌드 도구도 없어야 한다.

## 기본 원칙

1. 그림은 장식이 아니라 설명이다. 그림을 지워도 글이 성립하지 않는다면 그림이 아니라 의존성이다. 반대로 그림 없이도 글이 이해되는 자리에 그림을 넣지 않는다.
2. 한 그림에는 하나의 메시지. 흐름도는 흐름만, 비교는 비교만.
3. 텍스트는 15px 전후, 상자당 짧은 어구. 한글 긴 문장을 SVG에 넣지 않는다.
4. `<svg role="img">`에 `<title>`(또는 aria-label)로 그림 내용을 말해 준다. 스크린리더가 그림을 건너뛰지 않게.
5. 그림마다 `그림 N.` 캡션. 번호는 글 전체에서 순서대로(3-1 같은 편중 채번 금지 — 중간에 그림을 넣으면 전부 다시 세어야 한다).

## 다크 모드 대응

- 색을 하드코딩하지 않고 CSS 변수로 쓴다: `fill="var(--panel)"`, `class="t"`. 스타일시트에서 클래스별 fill/stroke를 정의하면 라이트/다크가 자동으로 바뀐다.
- 상태 색 약속(글 전체 일관): 성공=초록 `--ok`, 실패/위반=빨강 `--bad`, 경고/보류=노랑 `--warn`, 사용자/사람=보라, 강조/에이전트=파랑 `--accent`.
- 화살표 marker의 fill도 변수로. 문서 맨 앞에 `<defs>` 공용 마커를 하나 두고 `marker-end="url(#arr)"`로 재사용한다.

## 레이아웃 팁

- viewBox 기준 좌표로 배치한다(예: 760x300). 상자 너비는 텍스트 길이에 맞추고, 줄 간격 20~24px.
- 비교 그림은 왼쪽/오른쪽 또는 위/아래 패널로 나누고 패널 제목을 굵게.
- 강조할 행에는 빨간 테두리(`outline` 또는 두꺼운 stroke)를 둘러 "가장 극적인 줄"을 가리킨다.
- HTML 그리드(카드, 표, CSS 막대그래프)가 SVG보다 나은 경우도 많다. 규칙 나열은 카드 그리드, 수치 비교는 CSS 막대가 읽기 쉽다.

## 모바일

- 그림 컨테이너에 `overflow-x:auto`를 주고 SVG에 `min-width`(예: 640px)를 줘서 좁은 화면에서도 글자가 읽히게 한다. 캡션에 `↔ 옆으로 밀어서 보세요` 안내를 붙인다.
- 375px에서 가로 넘침이 없는지 반드시 실측한다(`verification.md`).

## 금지

- 장식용 AI 이미지·픽셀아트를 설명 도식 대신 넣지 않는다.
- 외부 이미지 URL, CDN 폰트, 스크립트를 넣지 않는다.
- 그림에 글 본문을 복붙하지 않는다. 그림 텍스트는 키워드만.
